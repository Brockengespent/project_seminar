# Трекер и LLM-консультант по индивидуальной образовательной траектории в ИТ

**Тема ВКР:** Разработка backend-сервиса трекера и LLM-консультанта по индивидуальной образовательной траектории в ИТ на основе графа навыков с оптимизацией производительности и расхода токенов.

**Автор:** Смирнов Г. В. (Университет ИТМО)  
**Научный руководитель:** Говоров А. И., старший преподаватель, факультет прикладной информатики  
**Технологический стек:** Python, Django / Django REST Framework, PostgreSQL, Redis, REST API внешней модели данных, LLM API (GigaChat, YandexGPT и др.).

